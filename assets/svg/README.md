# Девелопер — SVG-библиотека

Полноценная векторная библиотека в стиле «Премиальный архитектурный девелопмент». Используйте `manifest.json` для поиска ресурсов по стабильным ключам (`version: 1`). Каталог `catalog.json` документирует соответствие объектам игрового кода, но не содержит балансовых значений.

Визуальный PR не меняет HTML и не подключает изображения к игровому DOM. PROGRAMM интегрирует ресурсы отдельным проверенным PR. Цвет зонирования и маркер игрока следует выводить раздельно; доступные динамические параметры отображать в DOM.

См. `docs/art/PREMIUM_ARCHITECTURAL_DEV.md`, превью `previews/board-overview.svg` и `previews/cards-overview.svg`.
