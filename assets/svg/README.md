# SVG asset library — Девелопер

Здесь находятся **исходные SVG** для web-клиента. Готовые файлы поступают через PR в ветке `svg/*` и регистрируются в `manifest.json`. Этот файл — спецификация каталога, а не готовые художественные ассеты.

- Все иконки и иллюстрации остаются векторными, с `viewBox`, корректной обработкой HiDPI и доступными цветами.
- Названия файлов: `kebab-case.svg`; категории: `lots/`, `buildings/`, `cards/`, `ui/`.
- Не допускаются внешние шрифты, изображения, CSS/JS, `foreignObject`, обработчики событий и активные ссылки. Не вставлять base64 PNG.
- `assets/svg/manifest.json`: стабильные ключи, сопоставленные путям внутри `assets/svg`. Один ключ соответствует одному ассету.
- Публичные значения JSON — только пути, **никаких встроенных SVG строк**. Скрипт `node tests/svg-assets.cjs` проверяет структуру и ссылки.
- SVG PR должен содержать превью: общее поле и отдельно ассет при 1×, 2× и на телефоне. Не изменять числовые правила игры или HTML без согласования Programm.
- Художественные изменения подсоединяются к `visual.js` / `visual.css` в отдельном интеграционном PR после проверки совместимости, чтобы отсутствие SVG не нарушало базовый рендер.
