# Оценка v0.20 Design Edition

Это оценка первого интегрированного векторного исполнения, а не независимая экспертиза и не утверждение «10/10». Художественный эталон владельца остаётся целью приёмки.

Визуальная база: реальные Chromium screenshots из Actions [39241608868](https://github.com/bunkovde-lab/developer-web/actions/runs/39241608868), runtime SHA `209e8ae8623a9bf21b7d0a58e09ad08e591ae0c4`. Последующие коммиты меняют только проверки/документацию, не изображение игры. `before/` — замороженный main f91ac31; `premium-start-*` — новая партия; `premium-city-fixture-*` — явно подготовленные состояния настоящего renderer.

| Критерий | 0–10 | Основание |
|---|---:|---|
| Художественная цельность | 7 | Общие кремовые поверхности, золото, графит; старые второстепенные блоки ещё проще главного поля. |
| Соответствие референсу | 6 | Палитра и рамки приближены; векторная архитектура заметно проще детализированного растрового эталона. |
| Узнаваемость иконок | 7 | Молоток, каска, кран, щит, график; тонкие элементы теряются при минимальном размере поля. |
| Цветовая дифференциация | 8 | Контрастные дорожки и полосы зон, отдельный цвет владельца и золотое выделение торгов. |
| Архитектурная детализация | 6 | Окна, крыши, оборудование, деревья, парковки, склады; требуется дальнейшая художественная детализация для уровня эталона. |
| Читаемость | 7 | Данные из DOM, отдельные полосы; основной обзор на телефоне требует свайпа/zoom по утверждённой геометрии. |
| Удобство управления | 8 | Настоящие кнопки, сенсорные цели, торги на основной карте, компактный кабинет. Физический Android не проверен. |
| Качество карточек | 6 | Единая векторная серия, сохранённые реальные условия; иллюстрации семейств повторяются. |
| Качество интерфейса | 7 | Кабинет, портфель, обязательства, торговые окна согласованы. Не заявляется полное визуальное равенство референсу. |
| Производительность | 8 | Статический пакет около 1,96 МБ, нет добавленных runtime npm-зависимостей, проверка 18 повторных render в CI. Это не бенчмарк целевого планшета. |

## Приёмочный статус

Играбельная тестовая интеграция подготовлена, основной движок и числовые правила сохранены побайтно. Полная художественная приёмка не объявляется завершённой: детальность городских сцен и разнообразие иллюстраций карточек ниже утверждённого референса. PR остаётся draft до итогового просмотра PROGRAMM/владельцем; не объединять автоматически.

## Точный состав

`art-inventory.json` — 250 сформированных ресурсов. Manifest — 377. `changed-files.txt` перечисляет исходные изменённые пути; фактический полный актуальный diff доступен в PR #36. `engine-invariance.json` — побайтовое подтверждение сохранения встроенного ядра и семи модулей механик.
