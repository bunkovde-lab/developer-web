# QA — проверенные изменения

Каждый отчёт QA содержит дату, ссылку на commit/PR и baseline SHA, область механики, фиксированные seeds, число участников 3/4/5/6, статистику полных партий и распределение исходов, воспроизводимые тесты, сравнение экономических стратегий, известные ограничения.

Не присваивать метку «готово» на основании одного smoke-теста. Симулятор, Chromium и настоящая партия на устройстве — отдельные уровни качества.

Не исправлять тест отключением проверки без доказательства изменения утверждённого контракта. Новую экономику предлагать в отдельном PR; не менять релизную ветку напрямую.
