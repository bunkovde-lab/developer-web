# Девелопер — HTML v0.18.0: живой город и визуальный движок

**Основа:** HTML v0.17.0, `main` SHA `34dfaadc1cf5ffd79f6e0360634bf18dab71e59b`. Пакет художественных ресурсов SVG доставлен через PR #6 и объединён с `main` в `98c33317106c5140f8f2e6ecbadb9898de53ab3c`. 266 файлов зарегистрированы в `assets/svg/manifest.json`.

## Что интегрировано

- `scene-motion.js` — отдельный **неизменяющий игровой state** визуальный адаптер поверх `render`: сравнивает снимки состояния, испускает `developer:visual-event` с безопасными публичными метаданными, воспроизводит эффекты без вызовов денежных/игровых операций.
- `scene-motion.css` — изометрическая картография, оригинальные иллюстрации 24 участков, 32 клетки внешнего кольца, строительство 0–4 без создания новых игровых стадий, инженерные сети, цвета собственности, аренда, группы готовых смежных объектов, победные цепочки.
- Фишки используют **действительные позиции и итоговый результат 2d6**, анимационные промежуточные позиции не меняют результат броска. Два визуальных кубика всегда суммируются в уже бросившееся число; отдельные физические значения костей исходным движком не записываются.
- Карточки игрока получают реальный SVG по идентификатору колоды и варианту. Скрипт визуально не читает приватные карточные руки соперников; предложения рынка остаются под управлением существующих правил.
- Открытие/завершение **закрытого аукциона** отображает статус, но никогда не раскрывает ставки до фактического завершения. События купли, продажи и аренды сопровождаются короткими визуальными уведомлениями.
- Адаптивность: настраиваемые режимы «Плавно», «Быстро», «Без эффектов», ручной пропуск; `prefers-reduced-motion`; CSS без перехвата указателя на иллюстрациях.
- Звук: ранее существовавший Web Audio расширен регулировкой громкости и новыми короткими нотами. Звук инициируется только после пользовательского pointer/keyboard-ввода. Параметры звука/анимации сохраняются отдельно от игровой партии.
- Резервный вариант: при отсутствии / повреждении SVG-манифеста старые HTML-иконки и функциональность продолжают работать. После загрузки сохранённой партии прежние события не анимируются повторно.

## Событийный контракт визуала

`window.addEventListener('developer:visual-event', e => ... e.detail)` где `detail.type`:
`move`, `money`, `lot:acquired`, `lot:released`, `build:stage`, `lease`, `card:received`, `card:played`, `auction:start`, `auction:result`, `deal`, `win`.

**Контракт безопасности:** визуальная часть является потребителем состояния; обработчики событий не имеют права менять `state`. Никаких индивидуальных ставок соперников, скрытых карт или внутренней математики в payload. Дополнительные статусные элементы полностью удаляемы. Внешний API диагностики: `window.DeveloperMotion.status()`, `.setMode('normal'|'fast'|'off')`, `.skip()`, `.refresh()`.

## Остаточные ограничения

Не реализованы отдельные текстурированные кадры 3D-стройки, настоящие физические кубики по отдельности, сетевые скрытые руки людей, Android APK или полная ручная партия на устройстве. SVG на маленьком смартфоне дополнен семантическими HTML-метками и масштабированием; крупные архитектурные изображения удобнее смотреть в режиме «Увеличить город».
