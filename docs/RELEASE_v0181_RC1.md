# «Девелопер» — контрольная HTML v0.18.1-rc1

**Тип выпуска: Release Candidate / TEST. Не является стабильным релизом.**

## Источники

- Стабильная HTML v0.18 остаётся на корневой странице GitHub Pages; исходная точка: `7ece96d3315a2e5698c086122f356b7209fc658a`.
- RC1 строится из проверенной `main` после последовательного слияния **PR #11 → #14 → #15**.
- Отдельная тестовая ссылка: **https://bunkovde-lab.github.io/developer-web/previews/v0181-rc1/**
- Индикатор источника: `previews/v0181-rc1/RC1_SOURCE.json` и `previews/v0181-rc1/BUILD_INFO.txt` — оба доступны на GitHub Pages после деплоя. По ним проверяется конкретный SHA.

## Изменения Work

1. **PR #11:** устранение вложенных миниатюр внутри участков и внешнего игрового кольца; полноразмерное SVG-оформление без изменения библиотеки.
2. **PR #14:** компактные метки цены/района/стадии, корректное увеличение города, фокус клавиатуры и touch, отсутствие накопления картинок и устаревших значков инженерных сетей. Резервные HTML-метки при отказе отдельного SVG.
3. **PR #15:** учёт ходов AI через актуальный обработчик `endTurn`, защита от таймеров старой партии, проверка повреждённых сохранений, сохранение работоспособности без `localStorage`, исключение открытия человеческого паспорта из хода бота. В автоматические тесты добавлены реальные браузерные партии для 3 и 6 игроков.

Экономические коэффициенты, правила победы, колоды и набор 266 SVG не менялись.

## План приёмки и отчётность

После *каждого* merge используется GitHub Actions на конкретном SHA `main`. Для RC1 обязательны:

- Node тесты `smoke`, `territory`, `city-requests`, `pace`, `rework`, `tournament-v016`, `qa-mass-campaigns` (1000 партий), `svg-assets`, `finance-integrity`.
- Chromium `browser_marketplace`, `browser_city_requests`, `browser_visual`, `browser_territory`, `browser_finance`, `browser_living_city`, `browser_work_integration`, `browser_rc1_stability`.
- Публикация `Publish Developer Web`, контроль `RC1_SOURCE.json` на SHA `main`, проверка отдельного URL.
- **Android-плейтест владельца остаётся открытой приёмкой.** Успешный Chromium на Linux не является проверкой на физическом телефоне.

## Сохранения и ограничения

Путь превью отличается от основной страницы, **но GitHub Pages использует один домен**, следовательно `localStorage` у стабильной игры и RC1 может быть общим. Тестировать RC1 в отдельном профиле/приватной вкладке; не открывать существующую важную партию одновременно с тестовой.

Известные ограничения: 1 человек + 2–5 ботов, не реализован онлайн-мультиплеер; сложная партия 1–3 часа и нагрев/память на длительном Android-плейтесте не подтверждены; пользовательская художественная оценка поля и карточек ещё не проведена. В симуляторе большинство партий завершаются по лимиту 240 ходов, что само по себе не доказывает баланс.

**Критерий стабильности:** только после реального пользовательского тестирования и отдельного решения владельца проекта.
