# Решение по финалу — уточнение 17.10.2026 (книга правил v0.5.1)

## УТВЕРЖДЕНО
- Победа: первый игрок с четырьмя **собственными**, полностью построенными и **введёнными в эксплуатацию** объектами.
- Участки должны образовывать одну группу соседства **только по общей стороне**, горизонтально или вертикально. Диагональ не считается. Это ограничение остаётся от предыдущего решения, пока автор не уточнит его.
- **На каждом из четырёх объектов должен быть завершён этап строительной карточки «Инженерные сети»**, перед этапом «Ввод в эксплуатацию». В текущем HTML это отражает завершённая последовательность этапов проекта (`project.stage === 4`).

## ОТЛОЖЕННАЯ ИДЕЯ — НЕ РЕАЛИЗОВЫВАТЬ ПОКА
- Физическое соединение клеток/участков отдельными инженерными линиями, отображение труб/дорог/сетевых рёбер.
- Отдельное право собственности на линии, платный доступ к чужим линиям и граф инженерных подключений.
- Никаких отдельных сетевых линий для победы **не требуется**; достаточно статуса этапа «Инженерные сети» на карточке каждого объекта.

## Фактическое состояние
- В `index.html` предварительно есть проверка четырёх своих завершённых зданий с ортогональным соседством (сетка 6×5).
- Отдельная физическая сеть между участками отсутствует и сейчас не запланирована к реализации.
- Полная проверка браузерной партии с новым финалом не проводилась.

## Ожидается
Автор проекта продолжит объяснение механики. До уточнения не расширять топологию сетей и не менять другие утверждённые критерии финала.
