# SVG арт-протокол

Художник передаёт оригинальные `.svg` под `assets/svg/`, регистрирует новые ключи в `assets/svg/manifest.json` и прикладывает сравнение до/после. Основные категории: участки, архитектура, карты, интерфейс.

Проверять 390×844, 768×1024, 1024×768, 1366×900, контраст темного и светлого вариантов при наличии, touch-цели, масштабирование без растра, читаемость зон и принадлежности участка.

SVG не должен изменять цены, количество клеток, порядок карт или другие игровые правила. Программная привязка новых ключей выполняется Programm в отдельном PR.
