# Экономика 0.22 — 20 октября 2026

Зоны перемешаны с сохранением количества участков каждой зоны. Каждая из 18 прямых линий из четырёх клеток включает промышленную, деловую, многоэтажную или особую зону. Уникальные участки: №13 — Набережная, №17 — Транспортный узел.

|---|---:|
| Ж1 | 50 |

Ставка дана за малый/средний объект. Большой двухучастковый объект получает двойную обычную ставку. Сети и кризисы не меняют фиксированную аренду. Сети по прежним правилам влияют на продажу. Арендатор: восемь карт ×2, две карты ×3. Без карты действует ×1. Каждый отдельный готовый сосед по стороне добавляет 10% обычной ставки; бонус не умножается арендатором. Выплата при прохождении Старта; карта Работы также применяет аренду без требования арендатора.

Победа: четыре разных готовых здания в одной прямой горизонтальной или вертикальной линии. Завершения проектов, продажи и количество ходов победу не дают. Большое здание не считается двумя разными зданиями.

При отрицательных деньгах активы не стираются. Игрок выбирает продажу городу за 50% текущей базовой цены продажи готового здания либо торги игрокам. Незавершённый проект оценивается по земле, без возмещения незавершённых этапов. Если заняты два участка, в земельную оценку включаются оба. Проданный городу готовый объект остаётся на поле и участвует в соседских надбавках. На торгах одна ставка достаточна, победитель платит свою ставку. Если продавать нечего, отрицательная сумма записывается долгом и удерживается из следующих поступлений: нового капитала не создаётся.

События: 6 карт; кризисы: 4; налоговая: 3. Изъятия выбираются самим игроком и возвращают карты в соответствующий физический запас. Изъятие земли касается только участка без оплаченного первого этапа, не затрагивает начатые и готовые здания. Простое назначение проекта этапа 0 не защищает землю. Кризисы применяются по очереди ко всем игрокам. Скрытая плата за количество пустых участков отменена. Налог: 40 + 10 за готовое здание, максимум 100; юрист платит половину.

Старые сохранения требуют новой партии; прежнее состояние архивируется на устройстве перед стартом новой версии.
