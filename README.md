# developer-web

Браузерная рабочая версия настольной экономической игры «Девелопер». Не является полной реализацией на Godot 4.x; её правила и параметры необходимо сверять с основным GDD проекта.

## Правила

- [Действующие утверждённые поправки — готовые объекты и инженерные сети](docs/RULES_CURRENT.md).
- [История решения по инженерным сетям и тестовым параметрам](docs/DECISION_PROPERTY_NETWORK_BONUS_v0.5.4.md).
- [Решения по проектированию и стадиям](docs/DECISION_DESIGN_FIRST_v0.5.3.md).

Статусы в документах: **У** — утверждено, **Г** — гипотеза/тестовое число, **Р** — реализовано, **Т** — проверено тестом. Наличие коммита не свидетельствует о полном игровом тестировании или выпуске APK.

- [Баланс v0.7.0, результаты автоматических партий и блокирующие задачи Godot](docs/BALANCE_AND_RELEASE_GATES_v0.7.md).

**Браузерная тестовая версия:** https://bunkovde-lab.github.io/developer-web/?v=071. Кнопка «🤝 Обмен карт» доступна в свой ход после броска. В режиме одиночного тестирования доступны боты; мультиплеер с отдельными телефонами и итоговый Godot APK ещё не реализованы.
