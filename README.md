# developer-web

Браузерная рабочая версия настольной экономической игры «Девелопер». Не является полной реализацией на Godot 4.x; её правила и параметры необходимо сверять с основным GDD проекта.

## Правила

- [Действующие утверждённые поправки — готовые объекты и инженерные сети](docs/RULES_CURRENT.md).
- [История решения по инженерным сетям и тестовым параметрам](docs/DECISION_PROPERTY_NETWORK_BONUS_v0.5.4.md).
- [Решения по проектированию и стадиям](docs/DECISION_DESIGN_FIRST_v0.5.3.md).

Статусы в документах: **У** — утверждено, **Г** — гипотеза/тестовое число, **Р** — реализовано, **Т** — проверено тестом. Наличие коммита не свидетельствует о полном игровом тестировании или выпуске APK.

- [Баланс v0.7.0, результаты автоматических партий и блокирующие задачи Godot](docs/BALANCE_AND_RELEASE_GATES_v0.7.md).

**Браузерная тестовая версия:** https://bunkovde-lab.github.io/developer-web/?v=071. Кнопка «🤝 Обмен карт» доступна в свой ход после броска. В режиме одиночного тестирования доступны боты; мультиплеер с отдельными телефонами и итоговый Godot APK ещё не реализованы.

## Торговая площадка v0.8

В игровом кабинете нажмите **«🤝 Торговая площадка»**. В отдельном окне доступны все карты ботов, фильтры владельца и категории, поиск, покупка, продажа, обмен с доплатой, предложения цены и история сделок. Открывать площадку и заключать сделки можно только в свой ход на соответствующей клетке: **«Рынок» — инвесторы/покупатели/арендаторы, «Инженерные сети» — инженерные карты, «Сделка» — строительные карты**. Два основных действия и одна договорная сделка за ход. [Описание механики, ограничения и приватность](docs/MARKETPLACE_v0.8.md).

Проверка мобильного интерфейса через Chromium: [GitHub Actions — Marketplace browser UI](https://github.com/bunkovde-lab/developer-web/actions/workflows/browser-ui.yml). Наличие workflow не означает его успешного прохождения: смотрите статус последнего запуска.

## Правила v0.9

На «Старте» больше нет фиксированной выплаты; доход от действующих арендаторов при прохождении сохраняется. Госзаказы — три понятных муниципальных предложения без сроков и штрафов; инвестор закрепляется за отдельным проектом с автоматической продажей при вводе. Балансные значения стартового капитала и оплаты работы — испытательные. [Действующие правила](docs/RULES_CURRENT.md).
